Hello! This is the repository for my individual portfolio project for GDW VII. <br/>
Since the project proposal, I've added a lot more to my game, including hovering for the player movement, health and fuel bars for the UI, land mines that launch the player up, several sprites for the player, a few sound effects, and more. The first level is close to being complete, and will serve as a tutorial where the player can learn the game's controls and interact with some of the obstacles and other systems. <br/>
